Contoh Perintah untuk Agen AI

Tahap 1 · Rencana dan test plan
Aku membangun aplikasi [nama aplikasi] dari PRD berikut: [tempel isi PRD]. Susun rencana kerja per halaman dan
matriks akses untuk tiga peran. Lalu susun draf test plan minimal 15 test case yang merujuk kode BR, termasuk uji
negatif dan uji hak akses. Tampilkan dulu, jangan buat file apa pun sebelum aku setuju.
## Tahap 2 · Database
Ini ERD aplikasiku: [tempel penjelasan tabel]. Buat rencana migrasi untuk semua tabel, termasuk tabel profiles yang
terhubung ke auth.users, constraint dari aturan BR, dan RLS di setiap tabel per peran. Tampilkan SQL-nya dulu dan
jelaskan setiap policy. Tunggu persetujuanku sebelum menjalankannya lewat Supabase MCP.
Tahap 4 · Alur status
Kerjakan US-[nomor] sesuai PRD. Alur status yang berlaku: [tempel tabel alur status]. Perpindahan status yang tidak
diizinkan harus ditolak di database, bukan hanya disembunyikan di tampilan. Jelaskan rencanamu dulu, termasuk
BR yang terkait, lalu tunggu persetujuanku.
Tahap 5 · Operasi rawan bentrok
Operasi [nama operasi] bisa bentrok bila dua pengguna menjalankannya bersamaan. Rancang satu database
function yang mengunci baris terkait dengan for update, memeriksa peran pemanggil, memeriksa BR-[nomor], lalu
mengubah data dan menulis audit log. Tampilkan SQL dan cara mengujinya dulu, tunggu persetujuanku.
Tahap 8 · Tayang ke Netlify
Aku akan menayangkan aplikasi ini ke Netlify. Buat daftar langkah dan checklist: environment variable yang
dibutuhkan, pengaturan Auth Supabase untuk URL baru, noindex, dan pemeriksaan secret di repo. Tampilkan dulu,
jangan ubah file sebelum aku setuju.
